# Bannières de saison

Dessins SVG des bannières éphémères de Maison Hazparne.

| Fichier | Message | Basque | Période |
|---|---|---|---|
| noel.svg | Joyeux Noël | Eguberri on | 1er au 26 décembre |
| paques.svg | Joyeuses Pâques | Pazko on | lundi de Pâques − 19 jours → lendemain du lundi de Pâques |
| halloween.svg | Joyeux Halloween | Gau Beltza | 1er au 31 octobre |
| juillet.svg | Bonne fête nationale | Uztailaren 14a | 14 juillet |

À intégrer **en SVG inline** dans le HTML (pas en `<img>`) : le trait utilise `currentColor` pour suivre le thème clair/sombre, et les textes utilisent les polices de l'app (Hanken Grotesk, Fraunces).
